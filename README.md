# uwu owo i am gay

A gloriously extra terminal demo for people who believe pride should be loud, sparkly, and impossible to ignore.

## What it does

- prints a rainbow of terminal colors
- serves main-character energy in your shell
- ends with a very fabulous little flourish

## Run it

```bash
python3 gay_terminal.py
```
