# uwu owo i am gay

A tiny terminal demo that prints a very loud, very shiny pride message in your Linux shell.

## What it does

- prints colorful terminal lines
- shows a small rainbow block
- ends with a sparkly little slogan

## Run it

```bash
python3 gay_terminal.py
```

## Example

```text
hello from the gay terminal
love is loud
pride, chaos, and a little sparkle
██████
✨ stay fabulous ✨
```

## Notes
